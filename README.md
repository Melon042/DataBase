# DataBase (Учебный проект)

Консольное приложение для получения данных о работодателях и вакансиях от hh.ru API, сохранения и работы с ними через базу данных PostgreSQL.

# Запуск приложения
python main.py

# Комментарий
Настоятельно рекомендуется не удалять json-файлы без необходимости обновить данные, т.к. почему-то hh.ru зачастую отклоняет API запросы.
